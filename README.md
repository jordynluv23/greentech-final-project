# GreenTech Solutions Final Project

This website was made for the ICT280 final project. The client is GreenTech Solutions, which is a company focused on green technology and helping businesses lower their environmental impact.

## Project Description

This website gives visitors information about GreenTech Solutions, what the company does, what products and services it offers, and how people can contact the business.

## Target Audience

The main audience is small and medium-sized businesses that want to save energy, recycle better, and keep track of their carbon impact.

## How to Run the Project

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right click `index.html`.
4. Choose `Open with Live Server`.
5. Use the navigation menu to move through the website.
